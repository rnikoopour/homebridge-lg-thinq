# Security Policy

## Supported Versions

Only the latest published release receives security fixes.

| Version | Supported |
| --- | --- |
| 2.2.x | Yes |
| < 2.2 | No |

## Reporting a Vulnerability

Please do not open a public issue for security problems.

Use GitHub's private vulnerability reporting:

<https://github.com/rnikoopour/homebridge-lg-thinq/security/advisories/new>

Include the affected plugin version, Homebridge and Node.js versions, and steps to reproduce.
